# Unity Pro-FPS Controller

A clean, modular, and high-performance **First-Person Controller** for Unity. This script provides smooth locomotion, procedural camera movement, and built-in integration for animations and audio.

## 🚀 Features
*   **Smooth Movement:** Physics-based acceleration and deceleration.
*   **Crouch System:** Smoothly interpolated height and camera transitions.
*   **Procedural Head Bob:** Realistic camera swaying based on movement state.
*   **Integrated Hooks:** Automatic handling for `Animator` and `AudioSource`.
*   **Inspector Ready:** Organized headers for easy customization.

## 🛠 Setup
1. Attach `PlayerMovement.cs` to your Player GameObject.
2. Assign your **Main Camera** to the `Player Camera` field.
3. (Optional) Assign **Animator** and **AudioSource** for full feedback.

## 🕹 Controls
| Key | Action |
| :--- | :--- |
| **WASD** | Movement |
| **Left Shift** | Sprint |
| **Left Control** | Crouch |
| **Space** | Jump |
| **Mouse** | Look |
